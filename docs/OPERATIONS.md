# Эксплуатация кабинета

Практические действия для того, кто ведёт курс. Устройство таблиц и лимитов разобрано в [how_it_works.md](how_it_works.md).

## Первый запуск

Из `cabinet-app/` скопируйте `.env.example` в `.env`. Укажите read-only DSN учебной PostgreSQL и замените `CABINET_ADMIN_TOKEN` длинным случайным секретом. Затем:

```sh
make setup
make manifest-check
make dev
```

Кабинет откроется на `http://127.0.0.1:8000`. SQLite и локальные копии создаются в `var/`.

Если опубликованной версии ещё нет, кабинет читает локальный `manifest.course.json`. Студенты могут войти и до публикации. Образ Docker этот файл не копирует. В `.gitignore` он указан. Пока файл числится в индексе git, уберите его оттуда командой `git rm --cached manifest.course.json`: копия на диске останется.

В панели администратора откройте «Курс». Если файла ещё нет, редактор всё равно открывается: вставьте JSON или выберите файл, проверьте и опубликуйте. Публикация выполняет эталоны на учебной базе и сохраняет их результаты. Старые попытки не переписываются.

На ВМ без опубликованной версии положите тот же JSON в `/srv/sql-trainer/data/manifest.json` до пересборки. Команда есть в [deploy.md](deploy.md).

## Роли

Два отдельных входа. Ассистент на своей плашке вводит логин и пароль. Если права ассистента нет, кабинет пишет об этом и в панель не пускает. Администратор вводит логин, пароль и ключ. Ключ – это `CABINET_ADMIN_TOKEN`. В тексте формы его имя не пишется. Это одна роль: тот же человек публикует курс, видит журнал и выдаёт права.

Ассистент – учётная запись студента с включённым доступом в разделе «Права». Отдельный пароль для роли не выдаётся. Снять роль можно там же. Перезапуск кабинета снятую роль не возвращает.

Ассистент видит студентов, историю, выгрузки и ручную проверку. Курс, журнал и выдача прав доступны администратору.

Сброс пароля студента создаёт временный пароль, показывает его один раз и завершает сессии этого студента. Передайте пароль лично. В журнал он не пишется.

Логин: 4–32 символа, латиница, цифры, точка, дефис или `_`. При регистрации можно проверить, свободен ли логин.

## Оценки

Студент видит сырой балл задачи. Если преподаватель поставил ручную оценку, на карточке есть комментарий, автор и время.

Правило одно. Берётся последняя ручная оценка. Если после неё автоматическая проверка набрала больше, берётся наибольший из таких поздних результатов. Пока более позднего улучшения нет, на экране остаётся оценка преподавателя.

Ведомость и карточки считают этим правилом. Выгрузка вех хранит каждое сырое достижение и штраф по времени этого достижения. Если взять из вех максимум, можно увидеть старый балл, который ручная оценка уже заменила. Итог курса смотрите в ведомости.

После жёсткого срока обычная проверка закрыта и даёт 0 баллов. Открытие проверки для одного студента и одного задания требует причины и попадает в журнал.

## История

В редакторе можно смотреть схему учебной базы командами psql. Они только читают каталог и попытку проверки не создают.

Песочница хранит последние 10 запусков. На странице задачи запуски и проверки лежат в одной истории, старые записи подгружаются. Запрос из записи можно вернуть в редактор.

Каждая проверка создаёт новую попытку, даже если SQL тот же. В записи есть текст запроса, время, вердикт, длительность, число строк и урезанный результат. Черновик сохраняется отдельно и в журнал не пишется.

В журнале есть входы и неудачные входы, выходы, смена профиля и пароля, запуски, проверки, новые достижения, публикация курса, права, сброс пароля, ручные оценки, открытие срока, перепроверки и выгрузки. Фильтр – по действию и исполнителю. Карточка студента показывает действия, которые относятся к нему.

Список студентов ищет по логину и ФИО и фильтрует по заданию, задаче, баллам и статусу.

## Курс

«Манифест и правила» задаёт часовой пояс, сроки, задачи, условия, обязательные конструкции, подсказки, эталонный SQL и формулу штрафа. Формула – только арифметика и переменные `score`, `late_days`, `period_days`, `multiplier`, `max_penalty_fraction`.

Текущие сроки курса: мягкий `2026-09-25 23:59`, жёсткий `2026-10-10 23:59`, `Europe/Moscow`. Общий жёсткий срок в начале файла – значение по умолчанию. У задания свой срок важнее.

«Настройки» показывают путь к манифесту, хранилищу, часовой пояс и доступность учебной базы.

Перепроверка ответов идёт в том же процессе, не больше четырёх запросов сразу, и делит очередь с живыми проверками студентов. Одновременно выполняется одна такая работа. Если процесс перезапустили посреди неё, при старте она помечается как прерванная и не продолжается сама.

## Безопасность

Учебную базу подключайте отдельной ролью только на чтение. Запрос идёт в транзакции `READ ONLY`, обрывается через 15 секунд, блокировку ждёт не дольше 3 секунд, результат ограничен 100 000 строк и 20 МБ. На экране первые 200 строк. Одновременно идут 32 таких запроса. Остальные ждут до 20 секунд и затем просят повторить. Лимит соединений кластера больше, кабинет его целиком не занимает.

Пароли, DSN и секретную фразу не кладите в манифест, документацию, git и журнал. Им место в `.env`.

Пароли хранятся как PBKDF2-HMAC-SHA256. В базе лежат хеши токенов сессии. Сессия живёт 14 дней. Сброс пароля сессии отзывает.

Попытки, достижения, ручные оценки, запуски, результаты перепроверки и журнал нельзя изменить или удалить. Балл и запись о нём пишутся одной транзакцией.

Файл базы на POSIX имеет права `0600`. Каталог копий – `0700`, файлы копий – `0600`. Копия проверяется через `PRAGMA integrity_check` и хранится 7 дней. На сервере база и эти семь копий лежат на одном диске. Копия вне машины по-прежнему ручная.

Вход ограничивает сам процесс кабинета. В Caddy отдельного лимита нет. Перезапуск обнуляет это окно. Для публичного адреса нужен HTTPS.

Проверка `/health` спрашивает только SQLite. Недоступность учебной PostgreSQL контейнер из-за неё не перезапускает.

## Проверка изменений

```sh
make check
make manifest-check
node --check cabinet/static/app.js
node --check cabinet/static/sql-editor.js
```

Настоящие запросы к учебной базе гоняйте на тестовом DSN, не на боевом. Команды запуска и восстановления есть в [README](../README.md).
